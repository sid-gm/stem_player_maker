Snap, explained 🎚️

A plain-English, see-and-hear walkthrough of what the snap engine does.

THE BIG IDEA

Think of "snap-to-grid" in a design app — you drop a box near a line and it clicks neatly into place. We're doing the same thing, but for sound.

A song is built from short chunks that repeat (a chunk ≈ 1.7 seconds here — musicians call it a "bar"). The same musical figure comes back over and over, but each time the song is in a different musical "flavor" (musicians call it a chord) — so the figure is played a little higher or lower to fit.

The goal: you drop in your own sound once, and we automatically re-tune, re-time, and re-level it so it fits perfectly into every spot where that figure repeats — like autotune + auto-timing, done for you.

Below we prove the math works using the song's own sound as a stand-in for "your upload": we take the figure from one spot and snap it onto another spot that's in a different flavor. If it sounds right there, the engine works.
